# Arambol Connect

> **Goa's Premier Digital Growth, IT & CCTV Solutions**

An Apple-inspired, high-performance web experience for **Arambol Connect** — North Goa's leading technology, commercial security, and digital marketing agency based in Arambol.

---

## ⚡ Tech Stack

- **HTML5**: Semantic, single-file modern architecture.
- **Tailwind CSS**: Utility-first responsive design with custom dark theme (`#0B0F19`) & frosted glassmorphism (`backdrop-blur-xl`).
- **Three.js**: Interactive 3D particle constellation engine reacting dynamically to cursor depth and ambient parallax.
- **Lucide Icons**: Crisp, lightweight vector iconography.
- **Google Translate API**: Seamless native multilingual switching (English, Russian, Hindi, Hebrew, French, German, Spanish).

## 🚀 Deployment Instructions (GitHub Pages)

This project is completely self-contained in a single production-ready `index.html` file, requiring zero build steps or bundlers.

### Method 1: Via GitHub Web Interface
1. Push this repository to GitHub.
2. On GitHub, navigate to your repository's **Settings** tab.
3. In the left sidebar, click on **Pages** (under *Code and automation*).
4. Under **Build and deployment > Source**, select **Deploy from a branch**.
5. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
6. Click **Save**.
7. Within 1–2 minutes, your website will be live at:
   ```
   https://<your-username>.github.io/<repository-name>/
   ```

### Method 2: Via Git CLI
```bash
# Ensure your changes are committed
git add .
git commit -m "Initial commit: Arambol Connect Apple 3D Production Build"

# Push to your main branch
git push -u origin main
```
